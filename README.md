This is a screener and market dashboard based on the Substack written by Jeff Sun.  The scans.py file has all you need to run it.  The other file in the repository for rotation you can ignore.  I'm a newbee and didn't know I needed to set these up separately.
Simply runs the scans.py file and it will ouput all scan results in the panel as copyable, comma separated lists. click three times on a group of tickers and all will be highlighted to be copied to clipboard. Also, it will ouput into an excel file (change the excel fiel name to match 
one on your computer.
